## Alterações da MPDWorks

- `index.php` agora é a landing page principal da MPDWorks.
- `home.php` continua sendo a área interna após o login.
- `login.html` guarda a tela de login que antes era `index.html`.
- `cadastro.php` foi adicionada para cadastro básico.
- `landing.css` e `landing.js` são os arquivos da landing page.
- Foi adicionado o botão vermelho de **EMERGÊNCIA**.
- As imagens originais da landing estão sendo carregadas do branch `Front-end` do GitHub. Para deixar o projeto totalmente independente da internet, copie posteriormente as quatro imagens para uma pasta `assets/landing/`.
