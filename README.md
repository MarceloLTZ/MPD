# MPD Nexus

Plataforma de software para prestação de serviços e gestão de cuidados residenciais, com foco em manutenção corretiva e preventiva.

Projeto de conclusão de curso — SENAI Mauá "Jairo Candido", Técnico em Desenvolvimento de Sistemas, disciplina de Projeto de Software 2.

## Sobre o projeto

A falta de transparência e de acesso a profissionais qualificados em situações emergenciais gera custos desnecessários para famílias e empresas. O projeto propõe uma plataforma que conecta diretamente clientes a prestadores de serviços de manutenção residencial (construção, reparos, monitoramento preditivo, entre outros).

Principais funcionalidades:

- GPS para acompanhamento em tempo real do prestador
- Relatórios periódicos sobre o andamento do serviço
- Canais de suporte 24 horas
- Sistema para atendimentos emergenciais
- Histórico digital de intervenções, funcionando como um prontuário da residência

## Requisitos

### Funcionais (destaques)

- RF1 — Escolha do profissional mais próximo via GPS (Alta)
- RF2 — Cadastro com login e senha segura (Média)
- RF3 — Contratação de diferentes tipos de serviço (Alta)
- RF4 — Armazenamento de dados criptografado (Alta)
- RF5 — Pagamento com envio de comprovante por e-mail (Alta)
- RF6 — Relatórios periódicos do prestador (Média)
- RF7 — Registro cronológico de intervenções, prontuário digital (Baixa)
- RF8 — Alertas automáticos de manutenção preventiva (Média)
- RF9 — Checklist de conformidade com fotos antes e depois (Média)
- RF10 — Visita de diagnóstico prévia com laudo técnico (Média)

Lista completa de requisitos funcionais, não funcionais e de negócio no documento do projeto.

### Não funcionais (destaques)

- Disponibilidade 24/7
- Compatibilidade com dispositivos móveis e desktop
- Design responsivo
- Carregamento de páginas abaixo de 6 segundos
- Autenticação de dois fatores (2FA) obrigatória
- Compatibilidade nativa com Chrome e Firefox

### Negócio (destaques)

- Visualização de detalhes do serviço antes do cadastro
- Cancelamento gratuito dentro de um prazo definido
- Descontos para clientes bem avaliados
- Pagamento via débito, crédito e PIX (taxa de 15% para a plataforma)
- Espaço para anúncios e parcerias comerciais
